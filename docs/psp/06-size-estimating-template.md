Unidad/definición LOC requerida por la asignatura: **pendiente**.

| Categoría | Estimado | Real | Procedencia
|---|---:|---:|---|
| Código nuevo Java | pendiente | pendiente | Medir tras congelar versión
| Tests Java | pendiente | pendiente | Medir tras congelar versión
| Otros | pendiente | pendiente | Separar Markdown/YAML si el curso lo solicita
