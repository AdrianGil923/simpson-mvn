# PIP form (borrador)

**Problema/proceso:** actividad implementada; no se dispone de mediciones históricas por fase.

| Observación | Evidencia | Propuesta |
|---|---|---|
| Estado inicial era solo saludo y test trivial | Inspección del código y test | Anotar requisitos antes de codificar y diseñar casos al inicio |
| No había Git local | `git status` informó que no era repositorio | Inicializar y crear baseline cuando el estudiante autorice commit |

**Aprendizaje:** documentar restricciones de entrada, criterio de parada y referencias redondeadas. Añadir reflexiones personales y métricas al completar actividad.
